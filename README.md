# Textbook Hunter

A [Cubbie](https://cubbie.ai) Skill that finds the free or cheapest legal way to get each required textbook
(instructor's copy, open textbook, library, rental, used, older edition, digital) and texts you what you save
versus the bookstore.

## Install

Text this repository's link to Cubbie and reply "yes" when it asks. Then try:

```text
bookstore wants $289 for my books this semester, can you find me something cheaper?
```
